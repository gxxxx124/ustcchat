# DeepSeek-OCR 本地部署指南

本指南将帮助您从零开始部署 DeepSeek-OCR，实现 PDF 转 Markdown 的功能。

## 📋 前置要求

- **操作系统**: Linux (推荐 Ubuntu 18.04+)
- **GPU**: NVIDIA GPU (推荐 24GB+ 显存，如 RTX 3090/A100)
- **CUDA**: 11.8+ (系统级安装)
- **Python**: 3.12.9
- **Conda**: Anaconda 或 Miniconda
- **网络**: 可访问 ModelScope (国内镜像) 或 HuggingFace

---

## 🚀 部署步骤

### 步骤 1: 创建工作目录

```bash
# 创建项目目录
mkdir -p ~/deepseekocr
cd ~/deepseekocr
```

### 步骤 2: 克隆 DeepSeek-OCR 仓库

```bash
git clone https://github.com/deepseek-ai/DeepSeek-OCR.git
```

克隆完成后，目录结构如下：
```
deepseekocr/
├── DeepSeek-OCR/
│   ├── DeepSeek-OCR-master/
│   │   ├── DeepSeek-OCR-vllm/    # vLLM 推理脚本
│   │   └── DeepSeek-OCR-hf/       # Transformers 推理脚本
│   └── README.md
└── ...
```

### 步骤 3: 创建 Conda 环境

```bash
# 创建 Python 3.12.9 环境
conda create -n deepseek-ocr python=3.12.9 -y

# 激活环境
conda activate deepseek-ocr
```

### 步骤 4: 安装 PyTorch (CUDA 11.8)

```bash
pip install torch==2.6.0 torchvision==0.21.0 torchaudio==2.6.0 \
    --index-url https://download.pytorch.org/whl/cu118
```

**验证安装**:
```bash
python -c "import torch; print(f'PyTorch: {torch.__version__}'); print(f'CUDA available: {torch.cuda.is_available()}')"
```

### 步骤 5: 安装 vLLM

```bash
# 方法 1: 使用 pip 直接安装（推荐，如果您的网络可以访问 PyPI）
pip install vllm==0.8.5

# 方法 2: 如果网络受限，可以使用镜像源
pip install vllm==0.8.5 -i http://your-mirror-url/simple/
```

**验证安装**:
```bash
python -c "import vllm; print(f'vLLM version: {vllm.__version__}')"
```

### 步骤 6: 安装项目依赖

```bash
cd DeepSeek-OCR/DeepSeek-OCR-master/DeepSeek-OCR-vllm
pip install -r ../../requirements.txt
```

**requirements.txt 内容**:
```
transformers==4.46.3
tokenizers==0.20.3
PyMuPDF
img2pdf
einops
easydict
addict 
Pillow
numpy
```

### 步骤 7: 安装 ModelScope（用于下载模型）

```bash
pip install modelscope
```

### 步骤 8: 下载 DeepSeek-OCR 模型

由于网络限制，我们使用 ModelScope 下载模型：

```bash
cd ~/deepseekocr
python << 'EOF'
from modelscope import snapshot_download
import os

print("开始从 ModelScope 下载 DeepSeek-OCR 模型...")
model_dir = snapshot_download(
    'deepseek-ai/DeepSeek-OCR',
    cache_dir='./models'
)
print(f"✓ 模型下载成功！路径: {model_dir}")
EOF
```

**模型大小**: 约 6.21GB，下载时间取决于网络速度

### 步骤 9: 修复代码兼容性问题

由于系统 CUDA 版本可能与 PyTorch 不匹配，需要修复 flash_attn 导入问题：

```bash
cd ~/deepseekocr/DeepSeek-OCR/DeepSeek-OCR-master/DeepSeek-OCR-vllm
```

**修复 deepencoder/sam_vary_sdpa.py**:
```python
# 将第 13 行：
from flash_attn import flash_attn_qkvpacked_func

# 改为：
try:
    from flash_attn import flash_attn_qkvpacked_func
except ImportError:
    flash_attn_qkvpacked_func = None
    # 如果没有 flash_attn，将使用 PyTorch 的标准 attention
```

**修复 deepencoder/clip_sdpa.py**:
```python
# 将第 9 行：
from flash_attn import flash_attn_qkvpacked_func, flash_attn_func

# 改为：
try:
    from flash_attn import flash_attn_qkvpacked_func, flash_attn_func
except ImportError:
    flash_attn_qkvpacked_func = None
    flash_attn_func = None
    # 如果没有 flash_attn，将使用 PyTorch 的标准 attention
```

### 步骤 10: 配置模型路径

编辑配置文件 `DeepSeek-OCR-master/DeepSeek-OCR-vllm/config.py`:

```python
import os
# ModelScope 下载的本地模型路径
_base_dir = os.path.dirname(os.path.dirname(os.path.dirname(os.path.abspath(__file__))))
MODEL_PATH = os.path.join(_base_dir, '..', 'models', 'deepseek-ai', 'DeepSeek-OCR')
MODEL_PATH = os.path.abspath(MODEL_PATH)

# 修改 tokenizer 加载（添加 local_files_only=True）
TOKENIZER = AutoTokenizer.from_pretrained(MODEL_PATH, trust_remote_code=True, local_files_only=True)
```

## 📝 使用方法

### 方法 1: PDF 转 Markdown

**步骤 1**: 编辑配置文件 `config.py`

```python
INPUT_PATH = '/path/to/your/file.pdf' 
OUTPUT_PATH = '/path/to/output/directory'
```

**步骤 2**: 运行转换脚本

```bash
cd ~/deepseekocr/DeepSeek-OCR/DeepSeek-OCR-master/DeepSeek-OCR-vllm
conda activate deepseek-ocr
python run_dpsk_ocr_pdf.py
```

**输出文件**:
- `filename.mmd` - 清理后的 Markdown 文件
- `filename_det.mmd` - 包含检测框信息的原始输出
- `filename_layouts.pdf` - 带检测框可视化的 PDF
- `images/` - 提取的图片目录

### 方法 2: 单张图片 OCR

```bash
# 编辑 config.py 设置 INPUT_PATH 为图片路径
python run_dpsk_ocr_image.py
```

## 🔧 常见问题

### Q1: CUDA 版本不匹配

**问题**: 系统 CUDA 12.x 但 PyTorch 是 CUDA 11.8

**解决方案**: 
- vLLM 推理不受影响（vLLM 自带 CUDA runtime）
- 如需使用 Transformers 推理，需要安装 CUDA 11.8 toolkit

### Q2: flash-attn 安装失败

**问题**: 编译 flash-attn 时 CUDA 版本不匹配

**解决方案**: 
- vLLM 推理不需要 flash-attn（已修复兼容性）
- 代码已添加 try-except 处理，会自动降级到标准 attention

### Q3: 模型下载失败

**问题**: 无法连接 HuggingFace

**解决方案**: 
- 使用 ModelScope（已包含在步骤 8）
- 或配置 HuggingFace 镜像

### Q4: 内存不足

**问题**: GPU 显存不足

**解决方案**: 在 `config.py` 中调整：
```python
MAX_CONCURRENCY = 50  # 降低并发数
gpu_memory_utilization = 0.75  # 降低 GPU 内存使用率
MAX_CROPS = 4  # 减少图片裁剪数量
```
